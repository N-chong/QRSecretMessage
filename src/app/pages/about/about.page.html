Security & About

QRSecure

Password-protected encrypted QR messaging. Local-first and offline.

How your data is protected

Separate passwords

Your app PIN only unlocks this app. Each message has its own sender-created password, which is never inside the QR.

Modern encryption

Messages use AES-256-GCM. PBKDF2-SHA-256 derives a key from the message password using a fresh random salt and 310,000 iterations. Every message gets a new 96-bit IV.

Encrypted-only history

History stores ciphertext and QR metadata as local JSON. It never stores plaintext messages, passwords, PINs, or AES keys.

One-time limitation

One-time status is enforced only on this device. True global enforcement is impossible without a server because QR images can be copied. QRSecure intentionally uses no server.
